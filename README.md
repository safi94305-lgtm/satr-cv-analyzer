# سيرة — محلل السيرة الذاتية

واجهة عربية RTL بـ HTML وCSS وJavaScript، وخادم FastAPI يقرأ ملفات السيرة ويرسل النص إلى Groq. يدعم حاليًا PDF وDOCX وTXT حتى 10 MB. يعرض التحليل بالعربية ودرجة جاهزية عامة لأنظمة ATS. يمكن إضافة وصف وظيفة أو تدريب للحصول على درجة ملاءمة منفصلة ونسخة PDF مخصصة للإعلان. بعد ذلك يمكن إنشاء رسالة تقديم إنجليزية وتنزيلها PDF. إذا كانت السيرة بالعربية، ينشئ نسخة PDF إنجليزية. الملفات والنصوص وملفات PDF الناتجة تُعالج وقت الطلب ولا يحفظها التطبيق.

## التشغيل على Windows

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload
```

افتح `http://127.0.0.1:8000`. إعدادات Groq موجودة محليًا في `.env`، وهذا الملف مستثنى من Git. لتغيير المفتاح أو النموذج، عدّل `GROQ_API_KEY` و`GROQ_MODEL` هناك. لا تضع المفتاح في ملفات الواجهة.

ملفات PDF المصورة التي لا تحتوي نصًا قابلًا للاستخراج تحتاج OCR، وهو غير مضاف في النسخة الحالية. تحليل ATS يراجع النص المستخرج ولا يفحص الشكل المرئي للصفحة، ولا يضمن اجتياز أنظمة التوظيف. درجات الملاءمة إرشادية وتعتمد على المتطلبات والدليل الموجود في السيرة، ولا تضيف خبرات أو مهارات غير مذكورة.

## النشر المجاني على Render

يوجد ملف `render.yaml` بإعدادات FastAPI. ارفعي المشروع إلى مستودع GitHub، ثم في Render اختاري **New → Blueprint** واربطي المستودع. عند طلب قيمة `GROQ_API_KEY` أضيفي مفتاح Groq من إعدادات الخدمة؛ لا ترفعي ملف `.env` ولا تضعي المفتاح في Git. بعد انتهاء النشر يعطيك Render رابطًا عامًا للموقع.

خطة Render المجانية توقف الخدمة بعد 15 دقيقة من عدم الاستخدام، وقد يستغرق أول فتح بعد التوقف نحو دقيقة. نظام الملفات مؤقت، لذلك يعتمد التطبيق على معالجة الملفات في الذاكرة ولا يحفظ السير الذاتية.
